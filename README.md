# Ambient loop study — Hx Works

A self-initiated, original 20-second instrumental synthesis study for slow, sparse game ambience. No client commission, game assets, external recordings, samples or vocals were used.

- [Listen in the browser](https://hxsworrk-lab.github.io/ambient-loop-study/)
- [PCM WAV](ambient-loop.wav): stereo, 48 kHz, 16-bit, 20 seconds
- [Editable synthesis source](synthesize.py): Python with NumPy

The source uses additive oscillators, a short four-note motif and circular stereo delays. AI-assisted programming was used to produce the source. Run `python synthesize.py` in a Python environment with NumPy to reproduce the WAV and structural measurements.

The original exported file has no clipped samples; peak is about −8.14 dBFS and RMS about −20.00 dBFS. The adjacent sample change across the loop boundary is smaller than the largest internal adjacent change. These are structural checks, not proof of perceived seamlessness, professional music quality, engine integration or client acceptance. No subjective listening acceptance has been established.

This is a preview study. No soundtrack delivery, final source format, deadline or usage terms for a commission have been accepted. Any paid scope and its usage terms must be agreed separately.
